🔍 Reconnaissance คืออะไร?

Reconnaissance หรือ "Recon" คือขั้นตอนแรกของ penetration testing — การเก็บข้อมูลเกี่ยวกับ target ก่อนจะทดสอบช่องโหว่ ทำได้ ถูกกฎหมายเมื่อมีการอนุญาตหรือทดสอบในสภาพแวดล้อม lab

⚠️ ห้ามสแกน IP หรือ domain ของผู้อื่นโดยไม่ได้รับอนุญาต ถือเป็นความผิดตาม พ.ร.บ. คอมพิวเตอร์

Passive Recon (ไม่สัมผัส target โดยตรง)

  • whois domain.com — ดูข้อมูลเจ้าของโดเมน
  • nslookup domain.com — ค้นหา DNS records
  • OSINT tools เช่น Shodan, Maltego, Google Dorks
  • Wayback Machine สำหรับดูหน้าเว็บเก่า

Active Recon (ต้องมีใบอนุญาต)

  • nmap -sV 192.168.1.1 — scan ports และ service version
  • nmap -A target — aggressive scan (OS detection)
  • ping target — ตรวจว่า host ออนไลน์ไหม
  • traceroute target — ดูเส้นทาง network
💡 ฝึกได้ฟรีที่ scanme.nmap.org — เซิร์ฟเวอร์ที่ nmap ตั้งไว้สำหรับฝึกโดยเฉพาะ

Google Dorks ที่ควรรู้

  • site:example.com — ดูทุกหน้าของเว็บ
  • filetype:pdf site:example.com — หาไฟล์ PDF
  • intitle:"index of" — หา directory listing ที่เปิดไว้
  • inurl:admin — หน้า admin ที่ expose

🐧 Linux สำหรับ Security

Linux เป็น OS หลักที่ใช้ในวงการ cybersecurity เพราะยืดหยุ่น ควบคุมได้ลึก และมีเครื่องมือมากมาย Kali Linux และ Parrot OS เป็นตัวเลือกยอดนิยมสำหรับ pen tester

คำสั่งพื้นฐานที่ต้องรู้

  • ls -la — แสดงไฟล์ทั้งหมดรวม hidden files
  • chmod 755 file — เปลี่ยน permission
  • find / -name "*.conf" — ค้นหาไฟล์ config
  • grep -r "password" /etc/ — ค้นหา string ในไฟล์
  • ps aux — ดู process ทั้งหมด
  • netstat -tulpn — ดู port ที่เปิดอยู่
  • cat /etc/passwd — ดูรายชื่อ user
  • sudo -l — ดูสิทธิ์ sudo ของ user ปัจจุบัน

📱 Termux บน Android

Termux คือ terminal emulator สำหรับ Android ที่ให้ใช้ Linux commands ได้โดยไม่ต้อง root

💡 ดาวน์โหลด Termux ได้จาก F-Droid เท่านั้น (Play Store เวอร์ชันหมดอายุแล้ว)

คำสั่ง Termux เริ่มต้น

  • pkg update && pkg upgrade — อัปเดตแพ็กเกจ
  • pkg install nmap — ติดตั้ง nmap
  • pkg install python — ติดตั้ง Python
  • pkg install git — ติดตั้ง git
  • termux-setup-storage — เข้าถึง storage ของมือถือ
  • pkg install metasploit — ติดตั้ง Metasploit (lab only)
⚠️ เครื่องมือเหล่านี้ใช้ได้เฉพาะในสภาพแวดล้อม lab หรือระบบของตัวเองเท่านั้น

🕷️ OWASP Top 10

OWASP Top 10 คือรายชื่อช่องโหว่เว็บที่พบบ่อยที่สุด เป็นมาตรฐานที่นักพัฒนาและ pen tester ต้องรู้

  • A01 - Broken Access Control — ผู้ใช้เข้าถึงข้อมูลที่ไม่มีสิทธิ์
  • A02 - Cryptographic Failures — การเข้ารหัสที่อ่อนแอหรือไม่มีการเข้ารหัส
  • A03 - SQL Injection — ใส่ SQL command ผ่าน input
  • A04 - Insecure Design — ออกแบบระบบโดยไม่คำนึงถึง security
  • A07 - XSS (Cross-Site Scripting) — inject JavaScript เข้าไปในหน้าเว็บ

SQL Injection ตัวอย่าง (Lab เท่านั้น)

ใน form login ที่ไม่ได้ป้องกัน:

  • username: admin' -- — comment ออก password check
  • username: ' OR 1=1 -- — login ด้วยเงื่อนไขเป็นจริงเสมอ
💡 ฝึกได้ที่ DVWA (Damn Vulnerable Web Application) หรือ WebGoat ซึ่งออกแบบมาให้ทดสอบโดยเฉพาะ

เครื่องมือ Web Pen Test

  • Burp Suite — intercept HTTP requests, ทดสอบ web app
  • OWASP ZAP — ฟรี, auto scan หาช่องโหว่เว็บ
  • sqlmap — ทดสอบ SQL injection อัตโนมัติ
  • Nikto — scan web server หาช่องโหว่ทั่วไป

🌐 Network Security พื้นฐาน

การเข้าใจ network เป็นรากฐานของ cybersecurity ทุกอย่างไหลผ่าน network ก่อนถึงปลายทาง

Port ที่สำคัญ

  • 22 — SSH (remote login)
  • 80/443 — HTTP/HTTPS
  • 21 — FTP
  • 3306 — MySQL database
  • 3389 — RDP (Windows remote desktop)
  • 8080 — HTTP alternative

Wireshark เบื้องต้น

  • tcp.port == 80 — filter HTTP traffic
  • ip.addr == 192.168.1.1 — filter IP
  • http.request.method == "POST" — ดู POST requests
  • dns — ดู DNS queries
⚠️ การดักฟัง traffic ของผู้อื่นโดยไม่ได้รับอนุญาตเป็นความผิดทางกฎหมาย ใช้บน network ของตัวเองเท่านั้น

🔐 Cryptography พื้นฐาน

Cryptography คือศาสตร์การเข้ารหัสข้อมูล เป็นหัวใจของ security ทุกระบบ

ประเภท Hashing ที่ควรรู้

  • MD5 — ล้าสมัย อย่าใช้กับ password
  • SHA-256 — มาตรฐานปัจจุบัน
  • bcrypt — เหมาะกับ password hashing
  • argon2 — ใหม่ที่สุด ป้องกัน brute force ได้ดีที่สุด

คำสั่ง OpenSSL

  • openssl rand -hex 32 — generate random key
  • echo "text" | openssl dgst -sha256 — hash ข้อความ
  • openssl x509 -in cert.pem -text — อ่าน certificate

🏁 Capture The Flag คืออะไร?

CTF คือการแข่งขัน cybersecurity ที่ผู้เข้าแข่งต้อง "หา flag" ซึ่งเป็นข้อความซ่อนอยู่ในโจทย์ที่มีช่องโหว่ตั้งใจ เป็นวิธีที่ดีที่สุดในการฝึก

แพลตฟอร์มฝึก CTF

  • TryHackMe — tryhackme.com — เหมาะมือใหม่ มีคำแนะนำทีละขั้น
  • HackTheBox — hackthebox.com — ท้าทายขึ้น มี machine จริง
  • PicoCTF — picoctf.org — เน้นนักเรียน ฟรี
  • CTFtime — ctftime.org — ปฏิทินการแข่ง CTF ทั่วโลก
  • OverTheWire — wargames ฝึก Linux command line

หมวดหมู่ CTF ที่พบบ่อย

  • Web — SQL injection, XSS, authentication bypass
  • Crypto — ถอดรหัส cipher ต่างๆ
  • Forensics — วิเคราะห์ไฟล์, image, log
  • Reverse Engineering — วิเคราะห์ binary
  • OSINT — หาข้อมูลจากแหล่งสาธารณะ
💡 เริ่มที่ TryHackMe room ชื่อ "Pre-Security" — ครอบคลุมทุก concept ที่จำเป็น ใช้เวลาประมาณ 40 ชั่วโมง

เครื่องมือที่ใช้ใน Cybersecurity

nmap

Network scanner — สแกน port, service, OS ของ target ใช้ได้ใน Termux และ Linux
nmap -sV scanme.nmap.org scan service version (ตัวอย่าง host ที่อนุญาต)
nmap -A 192.168.1.1 aggressive scan local network
nmap -p 80,443 target scan เฉพาะ port ที่ระบุ

Termux packages

แพ็กเกจยอดนิยมสำหรับ security testing บน Android ผ่าน Termux
pkg install nmap python git ติดตั้งเครื่องมือพื้นฐาน
pkg install hydra password cracking tool (lab only)
termux-setup-storage ขอสิทธิ์เข้าถึง storage

whois / dig

เครื่องมือ OSINT สำหรับค้นหาข้อมูลโดเมน, DNS record และเจ้าของ IP
whois google.com ดูข้อมูล domain registration
dig google.com ANY ดู DNS records ทั้งหมด
nslookup -type=MX gmail.com ค้นหา mail server

netstat / ss

ดู connection ที่เปิดอยู่บนเครื่อง ใช้ตรวจสอบว่ามี process ผิดปกติหรือไม่
netstat -tulpn ดู port ที่กำลัง listen ทั้งหมด
ss -s สรุป socket statistics

hashcat / john

เครื่องมือ password recovery ใช้ทดสอบความแข็งแกร่งของ password hash
hashcat -m 0 hash.txt wordlist.txt crack MD5 hash ด้วย wordlist
john --wordlist=rockyou.txt hash.txt crack hash ด้วย john the ripper

curl / wget

เครื่องมือ HTTP ที่ใช้ทดสอบ API, ดู header, และส่ง request แบบกำหนดเอง
curl -I https://example.com ดู HTTP headers
curl -X POST -d 'data=test' url ส่ง POST request
